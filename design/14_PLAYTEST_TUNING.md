# 14 — PLAYTEST AND TUNING GUIDE

Do not tune by theoretical perfection. Tune by short repeatable tests.

## Flight feel test

Test for 60 seconds without objectives.

Questions:
- Can I turn toward something without fighting the camera?
- Does speed build visibly?
- Does diving feel faster?
- Is dash satisfying but controllable?
- Can I recover from a bad line without crashing constantly?
- Can I land intentionally?

If not, fix flight before anything else.

## Snatch test

Repeat Elder tutorial 10 times.

Target:
- first-time player can understand after 1–3 failures
- skilled player can execute consistently
- failure reads as their mistake, not hidden probability.

## Upgrade perceptibility

Immediately before/after each upgrade, repeat the same simple route.

Red must visibly shorten acceleration time.
Blue must visibly give more action budget.
Yellow must visibly shorten recovery waiting.
Green must visibly make timing easier.

If the player needs numbers to believe an upgrade happened, the effect is too subtle.

## Difficulty curve

Recommended subjective difficulty:
- Tutorial 1: trivial but satisfying
- Tutorial 2: easy
- Tutorial 3: moderate
- Red: moderate
- Blue: moderate
- Yellow: moderate+ due to context
- Green/child: hardest standard challenge.

The game should never become punishing.

## Ordinary Fry visibility

Run four tests:

1. New player who knows nothing.
   - Most should miss it initially.

2. Player deliberately scans first café.
   - Should be able to find it without clipping/hunting.

3. After 6 Prism Fries.
   - A reasonably observant player should have a fair chance.

4. After 12 Prism Fries.
   - Most players should converge toward finding it without an explicit objective arrow.

If everyone sees it immediately during tutorial, reduce contrast/angle — do not hide behind solid geometry.

If nobody can find it after 12 Prism, strengthen warm halo/chime range.

## Ending test

A good ending reaction is not necessarily "I understand the message."

Desired reactions include:
- pause
- laugh
- "oh"
- looking back at the world
- realization that the ordinary fry was present earlier.

If players feel lectured, remove explanatory text/effects.

If players think the game merely bugged out, make the `FRY / Tastes good.` presentation and HUD fade slightly clearer.
