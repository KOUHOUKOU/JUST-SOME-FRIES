# 10 — DELIVERY AND SUBMISSION CHECKLIST

This document is for the human + final integration agent.

## Final files

Keep a clean release folder containing:
- Windows executable/export
- required `.pck` / runtime files
- short README if needed.

Also retain source project separately.

## Recommended title description

**JUST SOME FRIES** is a short 3D game about a gull who only wants a few fries. Each stolen fry makes it faster, stronger and better at stealing the next one — until it has everything the game can give it and is still hungry.

Do not spoil the Ordinary Fry in the public short description if avoidable.

## Suggested theme framing

If the submission asks for the "Gift" framing:

**A gift for anyone who just wanted some fries.**

Internal interpretation:
The gift is not a reward item. It is the moment the player no longer needs the game to tell them what to want.

Do not over-explain this in the trailer.
