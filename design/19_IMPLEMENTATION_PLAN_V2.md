## 总原则

1. **手感优先于内容。** M1 不过,不进 M2。
2. **每个里程碑结束都必须是可玩的整体**,不允许长期处于"中间状态"。
3. **自动化先行**:`autotest.gd` 随功能同步升级(机器人必须能走完一遍并输出指标)。
4. **指标化**:机器人输出——各遭遇完成用时、失败次数、被拍次数、体力曲线、帧率。我们用数字判断难度,不靠印象。
5. **性能预算**:静态方块按材质合并;重复物用 MultiMesh;3D 节点总数 < 4000;目标 60 FPS。
6. **文字最小化**:任何新增玩家可见文字都要对照 §15 验收 5。
7. **不做**:P2 内容、对手海鸥、装饰抢夺物,直到 P0+P1 全部通过。

## M1 — 战斗机式飞行(闸门)

**范围**
- 速度分档:GLIDE 5 / THROTTLE 11 / BOOST 19 / BRAKE 2.5;能量守恒俯冲。
- 体力:巡航/加力/扇翅/翻滚耗,滑翔回,**落脚回(高处更快)**。移除巢。
- 镜头:FOV/距离随档位变化(§2.1);加力时速度线与风声。
- 翻滚闪避(A/D 双击)。
- 碰撞后果:翻滚失控、体力损失、镜头震动。
- 落水与 SOAKED。
- 落脚:任意可站面(含树顶盘、灯柱顶、桌面、屋顶、栏杆、船桅)。**落脚检测与"静止透镜"**。
- 海鸥模型:分段弯折翅、更流畅的扇翅/收翼/加力后掠、落地姿势;有 `hero_gull.glb` 则替换。
- 水面着色器 + 掠飞水花。
- **测试飞行场**(一块带树、柱、桌、屋顶、水面、障碍的空地)用于手感调参。

**验收**
- [ ] 滑翔明显慢且稳;按住 W 与 Shift 时**镜头与速度变化肉眼可见**。
- [ ] 体力耗尽不卡死;落脚后迅速恢复;**高处回得更快**。
- [ ] 撞击 > 9 m/s 翻滚,≤ 9 m/s 擦过。
- [ ] 贴水掠飞有水花,触水湿羽,落脚抖干。
- [ ] 翻滚能躲拍打(M2 之后复测)。
- [ ] **用户亲手试玩确认**(此项需要人)。

## M2 — 薯条、特写、失败代价

**范围**
- 薯条模型:盒装/盘装/手持,夸张尺寸、饱和金、棱线、光晕。普通薯条同级醒目但无光晕。
- 载体行为:盘装进食节奏;手持移动目标(手臂跟随)。
- 时机环改为**时间驱动**;按 E 即 COMMIT。
- **特写慢镜头**:相机切换、time_scale 0.15、黑边、低通、心跳;成功/失败/完美三种揭晓。
- 失败体系:遭遇 WARY(0–3)、载体升级、"NPC 吃光离开并 40 秒后重新出现"、镇子警惕(0–4)。
- 拍打类型:PUNCH / SWEEP / SQUIRT / POKE / LUNGE(狗)。其中 P0 先上 PUNCH / POKE / SQUIRT。
- 叫声诱饵、NPC 传染。
- 注意力节奏系统(低头/抬头、巡逻、转向)。

**验收**
- [ ] 同一遭遇连续失败 3 次后,NPC 带着薯条离开,40 秒后换位置重新出现。
- [ ] 特写慢镜头每次触发都不会卡相机,结束后控制权正常。
- [ ] 完美抓取有区别感。
- [ ] 盲测:玩家能说出"这次为什么被拍/为什么错过"。

## M3 — 地图与建模

**范围**
- 世界构建器重写为**模块化套件**(房屋/树/船/摊位/街道家具/灯塔/摩天轮/风车/起重机)。
- **静态合批**(按材质合并)+ MultiMesh。
- 地形高度场(山坡、海岬)。
- 分区 A–E(P0);F–H、I(P1)。
- 树顶/灯柱/屋顶/船桅等**落脚面**。
- 热气流柱、海风、峡谷风。
- 危险物:晾衣绳、旗绳、风车叶、摩天轮辐条、吊钩。
- 水面、天空、云片、灯光氛围。
- **氛围人物**:12 类,30–40 人,带行为(散步、慢跑、钓鱼、作画、服务员走动等)与简易程序动画(步行、吃、挥手)。

**验收**
- [ ] 任意 30 秒飞行,视野内都有人在动、有可落脚处、有可读挑战。
- [ ] 帧率:开发机 ≥ 60;降分辨率/关阴影后 ≥ 30。
- [ ] 机器人可飞遍所有分区而不卡死。
