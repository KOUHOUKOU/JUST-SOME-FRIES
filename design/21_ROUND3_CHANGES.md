## Decisions the user did not specify (change if you disagree)
* Vision needs the three tutorial fries (it is what they unlock). Before that TAB whispers "three fries first".
* A shot-down fry is not gone forever: the owner "reorders" it (otherwise a special fry could become unobtainable).
* Only owned fries get an escape check; star fries and decorative steals have a single check (nobody to swing at you).
* The crowd watch is a *number the player can read*, but it never blocks a steal — it only thins the bands.
* Progress counter is now n / 8 (3 tutorial + 5 tier-1 fries).
* Café lesson: the awning roof blocks dives from the roof, so the first fry must be approached from the front (the line-of-sight rule is why there is no lock through it).
