JUST SOME FRIES

Be a gull. Steal magic fries off a seaside pier, and find out what you were really hungry for.

Recommended: download the Windows version and play it locally. The browser version is only a light trial and may not run stably; the local version has clearer graphics and runs much more smoothly. / 推荐下载到本地游玩：网页版可能无法稳定运行，本地版画质更清晰、更流畅。
